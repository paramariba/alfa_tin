# Альфа Тин

«Альфа Тин» — учебный симулятор инвестиций для подростков. Он работает как самостоятельное веб-приложение и как встраиваемый модуль для Альфа‑Инвестиций. Пользователь изучает компании, совершает сделки на виртуальные TKN, получает доход с инвесткопилки, проходит уроки, развивает персонажа Тина и копит Alfa Coins на мерч.

В приложении нет реальных денег и настоящих брокерских заявок. Котировки используются только для игровой симуляции; выводы из новостей и ответы помощника не являются инвестиционными рекомендациями.

## Быстрый запуск

### Linux и macOS

Понадобятся Python 3 с `venv` и `pip`, Node.js 20.19+ или 22.12+ и npm. На macOS автоматическому скрипту также нужны Bash 4.3+ и команда `sha256sum` из GNU coreutils; без них используйте ручной запуск ниже.

```bash
chmod +x ./start.sh
./start.sh
```

Скрипт создаёт `.env` из `.env.example`, устанавливает зависимости, дожидается готовности backend и только затем запускает Vite. По умолчанию оба сервера слушают локальную сеть. После `Ctrl+C` скрипт завершает только запущенные им процессы.

```bash
./start.sh --no-browser
./start.sh --install-only
./start.sh --skip-install
APP_BIND_HOST=127.0.0.1 ./start.sh
```

На macOS файл [start.command](./start.command) вызывает тот же сценарий и наследует эти требования.

### Windows

Дважды откройте [start.bat](./start.bat) или выполните в PowerShell:

```powershell
.\start.ps1
```

### Ручной запуск

Backend на Linux и macOS:

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --env-file ../.env --host 0.0.0.0 --port 8000
```

Frontend:

```bash
cd frontend
npm ci
npm run dev -- --host 0.0.0.0
```

Приложение откроется на `http://127.0.0.1:5173`, OpenAPI — на `http://127.0.0.1:8000/docs`, проверка готовности — на `http://127.0.0.1:8000/health/ready`.

### Телефон в той же Wi‑Fi-сети

После `./start.sh` откройте на телефоне напечатанный адрес вида `http://192.168.1.23:5173`. Компьютер и телефон должны находиться в одной сети без гостевой изоляции клиентов. VPN может подменить IP или маршрут; для проверки его лучше временно выключить. Если страница не открывается, разрешите входящие соединения на TCP-порты 5173 и 8000 в локальном файрволе. Текущие Windows-скрипты слушают только `127.0.0.1`; для телефона на Windows запустите Uvicorn и Vite вручную с `--host 0.0.0.0`.

Ошибка Vite `ws proxy error: write EPIPE` означает, что frontend потерял соединение с backend. Текущий `start.sh` запускает Vite только после успешной проверки `/health/ready`. Если сообщение повторяется, убедитесь, что порт 8000 не занят другим процессом и оба сервера запущены одним экземпляром скрипта.

### Docker

```bash
docker compose up --build
```

Docker Compose собирает production frontend на Nginx, проксирует `/api` и `/ws` во внутренний backend и публикует приложение только на `127.0.0.1:8080`. Снаружи его следует открывать через системный Nginx или другой TLS reverse proxy. Backend и SQLite не публикуются отдельными портами.

## Первый сценарий

1. Зарегистрируйтесь по имени и паролю. Имя содержит 2–40 допустимых символов, проходит фильтр недопустимых слов; пароль — не меньше 6 символов.
2. Завершите знакомство. Стартовые 1 000 TKN начисляются один раз.
3. Откройте карточку компании или фонда и купите актив.
4. Дождитесь изменения котировки, затем продайте часть или всю позицию.
5. Положительная реализованная игровая прибыль станет доступна для обмена на Alfa Coins.
6. Пройдите уроки и задания: награды активности увеличивают результат следующей конвертации.
7. Выберите мерч-цель или купите предмет для Тина.

В магазине есть отдельная вкладка `Rostic’s`: вращение стоит 50 TKN, а восемь равновероятных секторов поровну разделены между небольшими призами и пустыми исходами. Выбор результата, списание и защита от повторного запроса выполняются на backend. Сейчас это демонстрационная механика: реальная выдача еды или промокода потребует отдельной партнёрской интеграции с Rostic’s.

Для презентации подготовлен пользователь `sasha` с паролем `demo1234`. В его профиле уже есть портфель и прогресс; это не стартовое состояние нового пользователя.

## Валюты и капитал

`TKN` — игровые деньги на свободном счёте, в акциях, фондах или инвесткопилке. Эти части складываются в общий капитал.

`AC` — Alfa Coins. Их получают при обмене только тех TKN, которые заработаны на положительной продаже или начислены как доход инвесткопилки. AC тратятся на мерч и косметику Тина.

`CT` — Contest Tokens. Они используются только в демонстрационном конкурсе и не смешиваются с TKN или AC.

Цена инструмента в игре равна цене источника в рублях, делённой на 100. Доходность позиции ускорена множителем 10, чтобы результат был заметен в коротком учебном сценарии. Положительный ускоренный результат продажи попадает в доступный к конвертации остаток; убыток уменьшает выплату, но не создаёт отрицательную квоту.

## Инвесткопилка и защита экономики

В инвесткопилку можно положить любую часть свободного TKN-баланса. Проценты считаются пропорционально точному времени хранения. Целые копейки зачисляются на свободный счёт и становятся доступными для конвертации, а дробный остаток переносится в следующий расчёт. Основная сумма вклада не считается заработком.

Курс TKN → AC плавно снижается с ростом капитала:

```text
rate = clamp(50 / sqrt(max(capital, 1000) / 1000), 5, 50)
```

Для защиты от временного вывода денег используется большее из двух значений: текущий капитал или его среднее за последние 30 дней. За скользящие 30 дней можно получить до 2 400 базовых AC, до 600 AC за активность и не более 3 000 AC суммарно. Если до лимита осталось меньше, чем даёт запрос, backend уменьшает списание TKN, поэтому деньги не сгорают без награды.

## Уроки и помощник

В приложении 18 уроков. Урок завершается после правильных ответов на три вопроса; кнопка завершения находится в конце прокручиваемой страницы. Повторное прохождение не выдаёт XP и boost второй раз. Уровень равен `floor(XP / 500) + 1`.

Помощник получает контекст урока отдельно от вопроса. Ответ ограничен JSON-схемой и правилами, запрещающими персональные команды купить или продать актив и обещания доходности. При ошибке модели возвращается безопасный подготовленный ответ. Это снижает риск галлюцинаций и prompt injection, но не даёт абсолютной гарантии.

Кулдауны действий с Тином хранятся и проверяются на backend отдельно для поглаживания, разговора и задания. Перезагрузка страницы не сбрасывает таймер, а параллельные запросы не позволяют получить повторную реакцию раньше времени.

## Сообщество

Публичный ID имеет формат `TIN-…`. Поиск работает по полному ID без учёта регистра. Дружба направленная: добавление пользователя не создаёт автоматическую взаимную связь.

В посте можно оставить до 300 символов, прикрепить собственную исполненную сделку и упомянуть известные инструменты, например `@TMOS` или `@YDEX`. Упоминания показываются красными ссылками на карточки активов. После первой покупки интерфейс предлагает поделиться событием. Свой пост можно удалить.

Фильтр брани отклоняет публикацию, а не блокирует аккаунт. Он нормализует регистр, пробелы и цифровые вставки. Модерация остаётся эвристической: перед публичным запуском нужны жалобы, аудит и управляемый словарь.

## Новости и месячный разбор

Новостной виджет выбирает до четырёх акций из портфеля по вложенной сумме. Backend ищет корпоративные события в доверенных источниках, удаляет повторы и разделяет факт и возможное деловое следствие. Прогноз цены и команда покупать или продавать запрещены. При отсутствии Gemini или сети используется детерминированный шаблон.

Месячный разбор строится на фактах из базы: сделках, конвертациях, операциях инвесткопилки и уроках. Ссылки на несуществующие действия отбрасываются. Результат кэшируется по месяцу и хешу входных данных.

## Рыночные данные

При `MARKET_DATA_PROVIDER=auto` backend сначала получает серверные котировки Finam, если задан `FINAM_API_SECRET`, а при ошибке автоматически переключается на публичный MOEX ISS. Данные ISS бесплатны, но задерживаются примерно на 15 минут. Режим `moex` использует только ISS, `finam` сохраняет MOEX как резерв, а `demo` включает искусственный поток. Секреты никогда не отправляются в браузер.

WebSocket `/ws/market` передаёт подборку котировок примерно раз в пять секунд. График в карточке инструмента загружается из дневных свечей MOEX; при временной недоступности ISS остаётся локальный резервный график.

## Встраивание в Альфа‑Инвестиции

`frontend/public/alfa-teen-invest-plugin.js` создаёт изолированный iframe. Контейнер может передать токен, тему, адреса API и WebSocket, открыть внутренний раздел и запросить обновление данных через `postMessage`. Встроенный режим не регистрирует service worker. При обычном открытии приложение продолжает работать как самостоятельная PWA.

Пример и типы находятся в [INTEGRATION.md](./INTEGRATION.md) и [integration/alfa-teen-invest-plugin.d.ts](./integration/alfa-teen-invest-plugin.d.ts).

## API

Все `/api/v1/*`, кроме регистрации и входа, требуют `Authorization: Bearer <token>`, если `AUTH_REQUIRED=true`.

* `/api/v1/auth`, `/onboarding`, `/dashboard` — аккаунт, смена пароля и главная;
* `/api/v1/market`, `/trades`, `/portfolio` — рынок, сделки и портфель;
* `/api/v1/economy`, `/piggy`, `/shop` — игровая экономика, магазин и колесо призов;
* `/api/v1/learning`, `/quests`, `/achievements`, `/streak` — обучение;
* `/api/v1/social` — пользователи, друзья и посты;
* `/api/v1/news`, `/coach` — новости и месячный разбор;
* `/api/v1/tamagotchi` — Тин и его предметы;
* `/api/v1/contest`, `/referrals` — демонстрационные механики;
* `/api/v1/admin/config` — настройка экономики.

Полный список приведён в [справочнике API](./docs/Alfa_Teen_Invest_Full_Documentation.md#справочник-api). Интерактивная схема доступна по `/docs` после запуска backend.

## PWA и офлайн-режим

Service worker регистрируется только в production-сборке и самостоятельном режиме. Он кэширует оболочку и статические ресурсы. API всегда использует сеть: торговля, запись прогресса и другие изменения офлайн недоступны.

## Известные ограничения

Проект готов для локальной демонстрации и дальнейшей интеграции, но не для публичного финансового сервиса без доработок.

* Выход удаляет токен на клиенте, но серверного denylist отозванных JWT нет.
* Доставка мерча имитируется, платёжной и логистической интеграции нет.
* Реферальный экран показывает 100/50 TKN, но погашение кода не реализовано.
* Конкурс, верификация и рейтинг демонстрационные; CT не связаны с реальными торгами.
* Задание на три сектора поддерживается API, но frontend не отправляет `sector_collect`.
* Социальный API всё ещё может вернуть сделки, хотя блок последних сделок убран из UI.
* SQLite и локальные фоновые задачи рассчитаны на один экземпляр backend.

## Правовой статус

Приложение является учебным прототипом. Перед production-запуском нужны юридическая проверка прав на данные и новости, политика обработки данных несовершеннолетних, правила модерации, безопасное управление секретами, журналирование административных действий и независимая проверка безопасности.
